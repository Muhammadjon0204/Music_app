# AURA — Дизайн-система

Статус: **Phase 3, предварительная версия.** Основана на референсе из
10 экранов (тёмная тема, розово-фиолетовые акценты). Значения могут
уточняться на Phase 4–5, когда появятся реальные экраны.

Код: `lib/presentation/design_system/` — импорт одной строкой:
`import 'package:music_app/presentation/design_system/design_system.dart';`

Каталог компонентов: `lib/presentation/dev/design_system_gallery_screen.dart`
(временно — стартовый экран приложения до Phase 4).

## Правила

1. **Цвета — только из токенов** (`context.auraColors`). Литералы
   `Color(0x…)` и `Colors.*` вне `tokens/` запрещены и ловятся тестом
   `test/architecture/no_hardcoded_colors_test.dart`.
2. **Текст — только стили `context.auraText`.** Шрифт не задаётся: на iOS
   это системный San Francisco, размер следует Dynamic Type.
3. **Всё нажимаемое — через `AuraPressable`** (или компоненты на его основе):
   мгновенный отклик, роль кнопки для VoiceOver, состояние disabled.
4. **Нет действия — нет кнопки.** `onPressed: null` делает элемент
   неактивным; карточки и строки без действия не объявляются кнопками;
   `AuraSectionHeader` не показывает «Все», если нет обработчика.
5. **Состояние не только цветом**: избранное — разные иконки
   (контур/заливка), активная строка — цвет + жирность + `selected`.
6. **Иконки без текста обязаны иметь `semanticLabel`** и зону ≥ 44×44 pt.
7. **Движение — через `AuraMotion`**: при Reduce Motion пространственные
   анимации убираются, затухания укорачиваются до 150 мс.
8. **Никаких бесконечных декоративных анимаций.** Скелетоны статичные;
   крутится только индикатор загрузки, пока идёт загрузка.

## Цвета (тёмная тема)

| Токен | Значение | Назначение |
|---|---|---|
| `background` | `#0B0B10` | Фон экранов |
| `surface` | `#15151D` | Карточки, поля ввода |
| `surfaceElevated` | `#1E1E28` | Нажатые строки, шиты, текущий трек |
| `border` | `#262631` | Разделители |
| `borderStrong` | `#4A4A58` | Контур вторичных кнопок |
| `textPrimary` | `#F5F5F7` | Основной текст |
| `textSecondary` | `#A6A6B2` | Исполнитель, подписи |
| `textTertiary` | `#868692` | Длительности, счётчики |
| `accent` | `#E0136F` | Залитые акценты: кнопки, переключатели, прогресс |
| `onAccent` | `#FFFFFF` | Текст на `accent` |
| `accentText` | `#FF5C9F` | Розовый текст и иконки на тёмном фоне |
| `accentSecondary` | `#8B5CF6` | Фиолетовый для градиентов |
| `error` | `#FF453A` | Ошибки |

Почему два розовых: белый текст на ярком `#FF2E88` из референса даёт
контраст ~3.5:1 (ниже нормы WCAG AA 4.5:1). Поэтому заливки используют
чуть более глубокий `accent` (≈4.7:1 с белым), а розовый **текст** на тёмном
фоне — более светлый `accentText`.

**Контраст проверяется тестом** `test/presentation/design_system/contrast_test.dart`:
все текстовые цвета ≥ 4.5:1 на `background`, `surface` и `surfaceElevated`.

## Размеры

- **Отступы** (сетка 4 pt): 2, 4, 8, 12, 16, 20, 24, 32, 48. Поля экрана — 20.
- **Радиусы**: 4 · 8 (обложка в строке) · 12 (карточки) · 16 (баннеры) ·
  24 (шиты) · pill.
- **Высоты**: кнопка 44 / 52, строка ≥ 64, мини-плеер 64, таб-бар 56 + safe area.
- **Ширина контента** на широких экранах ≤ 640 pt.

## Компоненты

| Компонент | Назначение |
|---|---|
| `AuraPressable` | Основа нажатий: scale / opacity / highlight |
| `AuraButton` | Primary (розовая «таблетка» со свечением) и secondary (контур); medium/large; loading без изменения размера |
| `AuraIconButton` / `.filled` | Иконка или круглая кнопка (play) |
| `AuraArtwork` | Обложка с градиентной заглушкой, плавное появление, декодирование под размер экрана |
| `AuraMediaCard` | Карточка альбома/плейлиста/исполнителя |
| `AuraListTile` | Строка трека/настройки/очереди, активное состояние |
| `AuraSectionHeader` | Заголовок секции с необязательным «Все» |
| `AuraLoadingState`, `AuraSkeletonBox`, `AuraListTileSkeleton` | Загрузка |
| `AuraEmptyState`, `AuraErrorState` | Пустое состояние и ошибка |
| `AuraStateSwitcher` | Плавная смена загрузка → контент → ошибка |
| `AuraPageTransitionsBuilder` | iOS-переход со свайпом назад; при Reduce Motion — затухание |
| `AuraTabBar` | Нижние вкладки: выбранная — розовая + залитая иконка + жирная подпись |
| `AuraSearchField` / `.button` | Нативное поле поиска iOS (≥ 44 pt) и кнопка, выглядящая как поле |
| `AuraProgressBar` | Прогресс с перемоткой пальцем и для VoiceOver (±10 с), время прошло/осталось |
| `AuraToggleButton` | Переключатель (shuffle, repeat): включённое состояние — подложка + цвет |
| `auraSheetTransition` | Экран, выезжающий снизу (плеер); при Reduce Motion — затухание |

Фон Now Playing строится из цветов обложки (`player_palette.dart`) и
проверяется тестом контраста для каждой палитры: текст под серединой
экрана и подпись «Демо» на тёмной подложке всегда читаемы.

## Известные ограничения

- В вебе и на Windows вместо San Francisco отображается системный шрифт
  платформы (Roboto/Segoe) — внешний вид на iPhone будет немного другим.
  SF Pro не встраивается: лицензия Apple это не разрешает.
- `Switch.adaptive` на iOS станет `CupertinoSwitch` — его цвета на
  реальном устройстве ещё не проверены.
- Светлая тема не реализована (структура токенов к ней готова).
